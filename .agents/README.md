# .agents/

Home for agent files that are not (yet) standardized.

The `.agents/` directory is an adopted community convention
(dotagentsprotocol.com, agentsfolder/AGENTS-1, ...) — **not a ratified
standard**. The layout below may change if a standard is standardized.

## Layout

| Path | Purpose |
| --- | --- |
| `README.md` | This file: documents the convention. |
| `skills/` | Agent Skills (`SKILL.md` format) kept out of the repo root. |

Standardized agent files stay at the repo root: `AGENTS.md`, `SKILL.md`.
